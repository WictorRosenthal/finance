# Instruções de Código

- Seguir as convenções já presentes no projeto.
- Priorizar clareza, legibilidade e manutenção.
- Manter funções, componentes e classes focados em uma responsabilidade.
- Evitar abstrações prematuras.
- Não adicionar dependências sem justificativa técnica.
- Preservar compatibilidade retroativa sempre que viável.
