# Instruções de Git

- Verificar o status do repositório antes de alterações relevantes.
- Não sobrescrever alterações não relacionadas do usuário.
- Não criar commits sem solicitação explícita.
- Não reescrever histórico sem autorização.
- Quando houver convenção de branch/commit já estabelecida no repositório, ela deve prevalecer.
- Em repositórios sem convenção clara, seguir as regras gerais do framework e confirmar com o usuário antes de adotar uma convenção mais formal.
