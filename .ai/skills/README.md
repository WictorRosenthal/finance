# Skills

As skills representam conhecimento técnico reutilizável. Neste bootstrap inicial, a estrutura foi criada sem adicionar skills tecnológicas específicas irrelevantes ao projeto.

## Estrutura esperada

```text
.ai/skills/
└── README.md
```

## Quando adicionar uma nova skill

- Quando a tarefa exigir conhecimento especializado e reaproveitável.
- Quando a stack do projeto justificar uma skill específica.
- Quando a skill for útil a vários agentes ou workflows.

## Skills sugeridas para este repositório

- `ponytail`
- `node`
- `react`
- `postgres`
- `infra`

Qualquer skill adicionada deve ser documentada em `SKILL.md` e ficar focada em conhecimento técnico, não em dados sensíveis do repositório.
