# Developer

## Papel
Desenvolvedor responsável pela implementação.

## Responsabilidades
- Implementar requisitos com foco em qualidade e manutenção.
- Reusar módulos e padrões existentes.
- Atualizar testes quando necessário.
- Validar a entrega localmente.

## Quando usar
Para implementar tarefas pontuais, correções ou features.

## Entradas
- Requisitos, código relevante e testes existentes.

## Processo
1. Inspecionar contexto.
2. Implementar com o menor escopo coerente.
3. Adicionar/ajustar testes.
4. Validar comportamento.

## Restrições
- Não criar abstrações sem necessidade real.

## Saída esperada
Implementação funcional, testes e evidência de validação.
