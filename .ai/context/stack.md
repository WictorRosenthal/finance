# Stack Tecnológica

## Frontend
- TypeScript
- React 19
- Vite 7
- TanStack Router e TanStack React Query
- Tailwind CSS 4
- Shadcn UI style components
- Cloudflare Vite plugin

## Backend
- Node.js
- TypeScript
- Fastify 4
- Drizzle ORM
- PostgreSQL via `postgres` / `pg`
- JWT, OAuth e autenticação local prevista (conforme `backend/src/infrastructure/auth/` e PRDs)

## Ferramentas de build/qualidade
- ESLint
- Prettier
- tsc
- Vitest (backend)

## Evidência
- `package.json` e `backend/package.json` confirmam as tecnologias.
- `backend/drizzle.config.ts` aponta para Postgres e Local DB.
- `wrangler.jsonc` indica uso de Cloudflare/TanStack Start.
