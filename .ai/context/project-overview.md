# Visão Geral do Projeto

Este repositório combina uma aplicação web em React com uma API backend em Fastify e persistência em PostgreSQL. O objetivo principal é gerenciar finanças e operações de conta, transações e convenções, com uma experiência de usuário tipo dashboard/CRUD em frontend e uma API direcionada a dados financeiros.

## Evidência direta
- `package.json` define frontend Vite + React + TanStack Router.
- `backend/package.json` define API Fastify + Drizzle + PostgreSQL.
- `src/` contém rotas e componentes da interface.
- `backend/src/` contém módulo de domínio, aplicação, infraestrutura e apresentação.

## Escopo
- Gestão de contas, convênios, transações e autenticação.
- API REST/JSON para o cliente.
- Persistência em banco relacional e estrutura orientada a módulos.
