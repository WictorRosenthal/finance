# Glossário do Projeto

## Contas
Conjuntos de contas financeiras e registros de movimentação do sistema.

## Convenios
Entidades/relacionamentos de parceria ou acordos financeiros.

## Transações
Operações financeiras registradas pelo sistema.

## Backend
API e lógica de serviços do projeto, localizada em `backend/src/`.

## Frontend
Aplicação web em React, localizada em `src/`.

## JWT/OAuth
Fluxos de autenticação previstos pela documentação do projeto e pelo backend.
