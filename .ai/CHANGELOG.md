# Changelog do `.ai/`

## [0.3.0] - 2026-10-07

Sincronizado com o `bob_framework` v1.9.0: a lista de comandos foi alinhada com as entradas atuais do framework, incluindo `/bob-update` e `/bob-adr`, e o carimbo de versão foi atualizado para refletir a sincronização com a base canônica do BoB.

## [0.2.0] - 2026-09-23

Adicionado o agente `Construtor Frontend` para implementacao de telas e fluxos React.

## [0.1.0] - 2026-09-23

Bootstrap inicial do framework para este repositório: estrutura `.ai/` criada com constituição, instruções, agentes, workflows, context, comandos, e adaptadores mínimos de provedor. O projeto foi inspecionado com base em `package.json`, `backend/package.json`, `src/`, `backend/src/` e a configuração de ferramentas do monorepo.
