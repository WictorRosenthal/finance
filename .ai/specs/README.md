# Specs

Esta pasta guarda requisitos, features e decisões relevantes ao projeto.

## Estrutura

```text
.ai/specs/
├── README.md
├── features/
├── requirements/
└── decisions/
```

## Uso

- `features/`: especificações de produto/funcionalidade.
- `requirements/`: requisitos de negócio e técnica.
- `decisions/`: decisões de arquitetura ou implementação relevantes.

Toda spec deve começar com uma seção de handoff resumindo escopo, contexto, empecilhos e decisões relevantes.
