# /bob-create-spec

## Descrição
Cria uma nova especificação de feature ou requisito.

## Sintaxe
`/bob-create-spec <slug>`

## Pré-condições
- Demanda clara.
- Contexto do projeto disponível.

## Aciona
Criação de `.ai/specs/features/<slug>/spec.md` e eventualmente `tasks.md`.

## Processo
1. Definir contexto e objetivo.
2. Registrar handoff.
3. Definir requisitos e critérios.
4. Escrever spec e, quando aplicável, tasks.

## Saída esperada
Spec documentada e pronta para implementação.
