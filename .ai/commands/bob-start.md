# /bob-start

## Descrição
Inicializa ou retoma o bootstrap do framework `.ai/` para este repositório.

## Sintaxe
`/bob-start`

## Pré-condições
- Repositório disponível.
- Verificação inicial de existência de `.ai/` e de configuração de IA.

## Aciona
Bootstrap completo, retomada de bootstrap incompleto ou sincronização de versão do framework.

## Processo
1. Verificar se `.ai/` já existe.
2. Conferir estrutura e versionamento.
3. Aplicar fluxo correspondente de descoberta, bootstrap ou sincronização.
4. Gerar preview quando necessário.

## Saída esperada
Estrutura `.ai/` pronta e consistente, com contexto do projeto e comandos disponíveis.
