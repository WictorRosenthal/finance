# /bob-security

## Descrição
Invoca o papel Security para revisar impactos em autenticação, dados e integrações.

## Sintaxe
`/bob-security`

## Pré-condições
- Mudança em autenticação, dados sensíveis, APIs ou integrações externas.

## Aciona
Agente Security.

## Processo
1. Revisar fluxo sensível.
2. Identificar riscos.
3. Sinalizar mitigação ou necessidade de revisão humana.

## Saída esperada
Relatório de riscos de segurança e recomendações.
