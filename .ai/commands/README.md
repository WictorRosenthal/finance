# Comandos do Framework

## Lista de comandos

- `/bob-start` — inicia o bootstrapping do framework ou apresenta o estado atual.
- `/bob-map-codebase` — mapeia o repositório e atualiza o contexto em `.ai/context/`.
- `/bob-concerns` — audita o código em busca de riscos de arquitetura e qualidade.
- `/bob-create-agent` — cria um novo agente em `.ai/agents/`.
- `/bob-create-skill` — cria uma nova skill em `.ai/skills/`.
- `/bob-add-skill` — instala uma skill externa aprovada.
- `/bob-add-mcp` — adiciona um servidor MCP aprovado.
- `/bob-create-spec` — cria uma spec de feature em `.ai/specs/features/`.
- `/bob-validate` — valida a estrutura do `.ai/`.
- `/bob-update` — sincroniza o `.ai/` com a versão atual do `bob_framework`.
- `/bob-adr` — registra uma decisão técnica relevante como ADR.
- `/bob-techlead` — invoca o papel Techlead.
- `/bob-architect` — invoca o papel Architect.
- `/bob-developer` — invoca o papel Developer.
- `/bob-reviewer` — invoca o papel Reviewer.
- `/bob-tester` — invoca o papel Tester.
- `/bob-researcher` — invoca o papel Researcher.
- `/bob-security` — invoca o papel Security.

A documentação canônica do framework fica em `.ai/` e os adaptadores específicos de ferramenta devem apontar para ela.
