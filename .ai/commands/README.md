# Comandos do Framework

## Lista de comandos

- `/bob-start` — bootstrap e retomada do framework.
- `/bob-map-codebase` — mapeamento de código e contexto.
- `/bob-concerns` — auditoria retrospectiva de riscos e arquitetura.
- `/bob-create-agent` — criar um agente novo em `.ai/agents/`.
- `/bob-create-skill` — criar uma skill nova em `.ai/skills/`.
- `/bob-add-skill` — adicionar skill externa aprovada.
- `/bob-add-mcp` — adicionar MCP aprovado.
- `/bob-create-spec` — criar spec de feature em `.ai/specs/features/`.
- `/bob-validate` — validar a estrutura `.ai/`.
- `/bob-techlead` — invocar Techlead.
- `/bob-architect` — invocar Architect.
- `/bob-developer` — invocar Developer.
- `/bob-reviewer` — invocar Reviewer.
- `/bob-tester` — invocar Tester.
- `/bob-researcher` — invocar Researcher.
- `/bob-security` — invocar Security.

A documentação canônica do framework fica em `.ai/` e os adaptadores específicos de ferramenta devem apontar para ela.
