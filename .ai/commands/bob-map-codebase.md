# /bob-map-codebase

## Descrição
Mapeia o repositório para atualizar arquivos de contexto em `.ai/context/`.

## Sintaxe
`/bob-map-codebase`

## Pré-condições
- Código do repositório disponível.
- Acesso a arquivos de contexto e documentação.

## Aciona
Agente Mapper e workflow de mapeamento.

## Processo
1. Verificar contexto atual.
2. Explorar área relevante.
3. Atualizar arquivos de contexto.
4. Registrar drift e lacunas.

## Saída esperada
Documentação atualizada do repositório com base em evidência.
