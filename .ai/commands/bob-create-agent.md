# /bob-create-agent

## Descrição
Cria um novo agente em `.ai/agents/`.

## Sintaxe
`/bob-create-agent <nome-do-agente>`

## Pré-condições
- `.ai/` existente.
- Nome do papel definido.

## Aciona
Criação de arquivo de agente com estrutura padrão.

## Processo
1. Validar necessidade.
2. Gerar arquivo em `.ai/agents/`.
3. Registrar versão no changelog do `.ai/`.

## Saída esperada
Agente novo documentado e pronto para uso.
